# 🛸 UFO Tracker — Catálogo & Análise de Avistamentos

> **Aplicação web para catalogação, padronização e análise estatística de fenômenos aéreos não identificados.**

O **UFO Tracker** resolve o problema da dispersão e falta de padronização no registro de relatos ufológicos. Ele substitui anotações informais e planilhas por uma interface centralizada, moderna, rápida e intuitiva.

---

## ✨ Destaques & Funcionalidades

- 📊 **Dashboard Interativo**: Exibe métricas consolidadas em tempo real (Total de casos, contagem de Alta Estranheza e Média de Credibilidade das testemunhas).
- 🧮 **Cálculo de Estranheza Automático**: Algoritmo dinâmico que pontua e classifica o caso em *Baixa (L)*, *Média (M)* ou *Alta (H)* levando em conta duração, formato, credibilidade e número de testemunhas.
- 🔍 **Filtros & Busca Dinâmica**: Pesquisa instantânea por localização (Cidade/UF) combinada a filtros por formato do objeto, nível de credibilidade e status do caso.
- 📝 **Modal de Cadastro em Tempo Real**: Formulário responsivo com cálculo dinâmico de prévia da pontuação e classificação durante a digitação.
- 👁️ **Análise Detalhada & Gestão**: Modal de visualização completa do relato e capacidade de arquivar ou desarquivar casos resolvidos/antigos.
- 🎨 **Interface Temática**: Design responsivo com *Dark Mode* nativo, inspirado em centros de inteligência e controle espacial.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica e modal acessível.
- **CSS3**: Estilização moderna, CSS Grid, Flexbox e efeitos com animações em CSS.
- **JavaScript (ES6+)**: Manipulação de DOM, algoritmo de pontuação e gerenciamento do estado dos filtros.

## 🚀 Como Executar o Projeto

Como o projeto utiliza tecnologias nativas do front-end, não é necessário instalar dependências ou gerenciadores de pacotes.

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/seu-usuario/ufo-tracker.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd ufo-tracker
   ```

3. **Abra o arquivo `index.html` no seu navegador:**
   - Dica: Utilize a extensão **Live Server** do VS Code para uma melhor experiência de desenvolvimento.
